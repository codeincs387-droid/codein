Q1
MCQ
Which operator is used to access a member of a structure using a structure pointer?
  • (a) .
  • (b) >
  • (c) ->
  • (d) =>
✓ Correct option: (c) ->

The arrow operator -> is used to access a structure member through a pointer to that structure, e.g. ptr->balance. The dot operator . is used only when accessing a member directly on a structure variable (not a pointer).

Q2
MCQ
Which of the following statements is CORRECT?
  • (a) Structure and union are the same
  • (b) A structure cannot reference itself
  • (c) An array of structures is not possible
  • (d) A structure can be passed to a function as an argument
✓ Correct option: (d) A structure can be passed to a function as an argument

Structures can be passed to functions by value or by reference (pointer), just like other data types. The other statements are false: structures and unions differ in memory layout (structures allocate space for every member, unions share one space); a structure can reference itself indirectly via a pointer (self-referential structure); and arrays of structures are commonly used (e.g. struct Student list[50];).

Q3
MCQ
Which of the following statements is INCORRECT?
  • (a) Unary operator takes only one operand
  • (b) A string is an array of characters
  • (c) malloc() function is used for dynamic memory allocation
  • (d) The data members of a structure must be of the same data type
✓ Correct option: (d) The data members of a structure must be of the same data type

This is false — a key feature of structures is that they can group members of different data types together (e.g. an int, a char array, and a float in the same structure). Statements (a), (b), and (c) are all true.

Q4
VSQ
What is a command-line argument?
Answer

A command-line argument is a value passed to a C program at the time it is executed from the command line, rather than entered interactively while the program runs. These arguments are received by main() through the parameters int argc (argument count) and char *argv[] (argument values, as strings), e.g. running ./program hello 5 passes "hello" and "5" as arguments.

Q5
VSQ
When should we use a union instead of a structure?
Answer

A union should be used when only one of several possible members needs to be stored and accessed at a time, and memory is a concern — all members of a union share the same memory location, so its size equals that of its largest member rather than the sum of all members. This is useful for representing variant data (e.g. a value that could be an int, float, or char depending on context) without wasting memory on unused fields, unlike a structure which allocates separate space for every member.

Q7
LQ
Explain various file opening modes in C with examples.
Answer

File modes are specified as the second argument to fopen() and control how the file is accessed:

ModeMeaning
"r"Open an existing file for reading only; fails if the file doesn't exist.
"w"Open for writing; creates a new file, or truncates (erases) an existing one.
"a"Open for appending; creates the file if it doesn't exist, writes are added at the end.
"r+"Open an existing file for both reading and writing.
"w+"Open for reading and writing; creates a new file or truncates an existing one.
"a+"Open for reading and appending; creates the file if needed.
"rb"/"wb"/"ab"Same as above but in binary mode instead of text mode.
FILE *fp = fopen("data.txt", "w");
if (fp != NULL) {
    fprintf(fp, "Hello, file!\n");
    fclose(fp);
}
Q8
MCQ (g)
What is the difference between a structure and a union?
  • (i) Structures share memory; unions do not
  • (ii) Unions share memory; structures do not
  • (iii) Both share memory
  • (iv) None of the above
✓ Correct option: (ii) Unions share memory; structures do not

All members of a union occupy the same memory location (so the union's size equals that of its largest member), meaning only one member holds a valid value at a time. A struct allocates separate memory for each member, so the total size is roughly the sum of all its members' sizes.

Q9
VSQ (i)
What is a self-referential structure? Provide an example use case.
Answer
struct Node {
    int data;
    struct Node *next;  // pointer to another Node
};

A self-referential structure is a structure that contains a pointer to another instance of the same structure type. A structure cannot directly contain a member of its own type (that would require infinite memory), but it can hold a pointer to one, since a pointer has a fixed, known size.

This is the foundation for building dynamic linked data structures such as linked lists, stacks, queues, and trees, where each node needs to reference the next (or child) node.

Q10
SQ (i)
Explain the modes of opening a file (r, w, a, etc.) in C with example.
Answer
  • "r" — read only; the file must already exist.
  • "w" — write only; creates a new file or erases the contents of an existing one.
  • "a" — append; writes are added to the end of the file, creating it if it doesn't exist.
  • "r+", "w+", "a+" — the "+" variants allow both reading and writing, differing in whether the file must exist and whether it's truncated.
#include <stdio.h>

int main() {
    FILE *fp = fopen("notes.txt", "a");  // append mode
    if (fp == NULL) {
        printf("Error opening file\n");
        return 1;
    }
    fprintf(fp, "New entry added.\n");
    fclose(fp);
    return 0;
}
Q11
SQ (j)
Explain command-line arguments in C. How are they useful in program execution?
Answer

Command-line arguments let a user supply input to a C program at the moment it is launched, via the terminal, instead of the program prompting for input interactively. They are received through two special parameters of main(): argc (the count of arguments, including the program name) and argv[] (an array of strings holding each argument, with argv[0] being the program's name).

They are useful for automating and scripting program execution — e.g. specifying an input filename, a mode flag, or configuration values directly when running the program (./sort data.txt -desc) without needing interactive prompts.

#include <stdio.h>

int main(int argc, char *argv[]) {
    int i;
    printf("Number of arguments: %d\n", argc);
    for (i = 0; i < argc; i++)
        printf("argv[%d] = %s\n", i, argv[i]);
    return 0;
}

Q13
LQ (e)
What is a file pointer? How is it used to manage file operations in C? Illustrate with an example program to read and write data to a file.
Answer

A file pointer is a pointer of type FILE * (defined in stdio.h) that holds information about an opened file — such as its current read/write position, buffering, and error status. It is obtained by calling fopen() and is passed to nearly every file-handling function (fprintf, fscanf, fread, fwrite, fclose, etc.) so they know which file to operate on. When file operations are finished, fclose() releases the file pointer and flushes any buffered data to disk.

// Write to a file, then read it back
#include <stdio.h>

int main() {
    FILE *fp;
    char line[100];

    // Writing to the file
    fp = fopen("greet.txt", "w");
    if (fp == NULL) {
        printf("Could not open file for writing\n");
        return 1;
    }
    fprintf(fp, "Hello from C file handling!\n");
    fclose(fp);

    // Reading the file back
    fp = fopen("greet.txt", "r");
    if (fp == NULL) {
        printf("Could not open file for reading\n");
        return 1;
    }
    while (fgets(line, sizeof(line), fp) != NULL)
        printf("%s", line);
    fclose(fp);

    return 0;
}
Output
Hello from C file handling!

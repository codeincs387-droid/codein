Q1
MCQ
Which of the following keywords is used to jump the control from one line to another?
  • (a) for
  • (b) goto
  • (c) jump
  • (d) if
✓ Correct option: (b) goto

goto is C's unconditional jump keyword — it transfers control directly to a labeled statement elsewhere in the same function. for is a loop construct, if is a branching construct, and jump is not a C keyword at all.

MCQ
Which of the following is a valid way of declaring a 2D array in C?
  • (a) int A[];
  • (b) int A;
  • (c) int A;
  • (d) int A[];
✓ Correct form: int A[rows][cols]; — e.g. int A[2][3];

A valid 2D array declaration must specify two dimensions in square brackets, e.g. int A[2][3];. A plain int A; declares a single integer (not an array at all), and int A[]; with empty brackets is only valid as a function parameter or when immediately initialized — it doesn't declare a usable 2D array either way.

Q5
SQ
Write any five limitations of an array.
Answer
  • Fixed size: the size must be known and set at declaration; it cannot grow or shrink at run time.
  • Memory wastage: if fewer elements are used than declared, the unused space is wasted.
  • Homogeneous data only: all elements must be of the same data type.
  • Costly insertion/deletion: inserting or deleting an element (except at the end) requires shifting many other elements.
  • No built-in bounds checking: C does not automatically prevent out-of-range access, which can cause undefined behavior.

Q7
SQ
Write a C program to accept a number and check whether it is a SUPERSPY (Spy) number or not.
Example Program
// Spy number: sum of digits equals product of digits
#include <stdio.h>

int main() {
    int n, digit, sum = 0, product = 1;

    printf("Enter a number: ");
    scanf("%d", &n);

    while (n > 0) {
        digit = n % 10;
        sum += digit;
        product *= digit;
        n /= 10;
    }

    if (sum == product)
        printf("It is a Spy number\n");
    else
        printf("It is not a Spy number\n");

    return 0;
}
Output (sample: 1124)
Enter a number: 1124
It is a Spy number

Note: a "Spy number" is one whose digits sum to the same value as their product (e.g. 1+1+2+4 = 1×1×2×4 = 8). This matches the term "SUPERSPY" as commonly used in this exercise.

Q8
LQ
What do you mean by a multi-dimensional array? Write a program to find the sum of the elements of each individual row of a 4×5 matrix.
Answer

A multi-dimensional array is an array of arrays — data organized using two or more indices, such as rows and columns (2D) or higher (3D and beyond). A 2D array like int A[4][5] stores 4 rows of 5 elements each and is commonly used to represent matrices, tables, or grids.

Example Program
// Sum of each row of a 4x5 matrix
#include <stdio.h>

int main() {
    int A[4][5], i, j, rowSum;

    printf("Enter 20 elements (4x5 matrix):\n");
    for (i = 0; i < 4; i++)
        for (j = 0; j < 5; j++)
            scanf("%d", &A[i][j]);

    for (i = 0; i < 4; i++) {
        rowSum = 0;
        for (j = 0; j < 5; j++)
            rowSum += A[i][j];
        printf("Sum of row %d = %d\n", i, rowSum);
    }

    return 0;
}
Output (sample: rows of 1-5, 6-10, 11-15, 16-20)
Sum of row 0 = 15
Sum of row 1 = 40
Sum of row 2 = 65
Sum of row 3 = 90

  • (iii) Executes only if explicitly called

Q11
VSQ (d)
Describe the syntax and use of the if-else-if ladder with an example.
Answer

The if-else-if ladder tests a series of conditions in order and executes the block for the first true condition, falling back to a final else if none match. It's used when there are multiple, mutually exclusive conditions to check.

int marks = 75;

if (marks >= 90)
    printf("Grade A\n");
else if (marks >= 75)
    printf("Grade B\n");
else if (marks >= 60)
    printf("Grade C\n");
else
    printf("Grade D\n");
Q12
VSQ (e)
Explain two differences between while and do-while loops with examples.
Answer
  • Condition check timing: while checks the condition before executing the body (entry-controlled), while do-while checks it after executing the body once (exit-controlled).
  • Minimum executions: a while loop's body may run zero times if the condition is false initially; a do-while loop's body always runs at least once, regardless of the condition.
// while: condition checked first
int i = 10;
while (i < 5) {
    printf("%d\n", i);   // never runs
}

// do-while: body runs at least once
int j = 10;
do {
    printf("%d\n", j);   // runs once, prints 10
} while (j < 5);

    printf("Enter a number: ");
    scanf("%d", &n);

    else
        printf("%d is not a palindrome\n", original);

    return 0;
}

Q14
SQ (d)
What is the difference between break, continue, and goto statements? Discuss their usage with examples.
Answer
  • break: immediately terminates the nearest enclosing loop or switch statement, and execution continues after it.
  • continue: skips the rest of the current loop iteration and jumps to the loop's next condition check/update, without exiting the loop entirely.
  • goto: transfers control unconditionally to a labeled statement anywhere within the same function, regardless of loop or block structure — generally discouraged as it can make code harder to follow.
for (int i = 1; i <= 5; i++) {
    if (i == 3) continue;   // skip 3
    if (i == 5) break;      // stop before 5
    printf("%d ", i);        // prints: 1 2 4
}

goto end;
printf("skipped\n");
end:
    printf("jumped here\n");
Q15
SQ (e)
Explain the concept of arrays in C. Discuss the difference between single-dimensional and multi-dimensional arrays.
Answer

An array is a collection of elements of the same data type stored in contiguous memory locations, accessed using a common name and an index. Arrays let a program store and process many related values (like a list of scores) using a single variable name instead of many separate variables.

Single-dimensional (1D) arrays hold a linear list of values, accessed with one index — e.g. int marks[5];, accessed as marks[2].

Multi-dimensional arrays hold data arranged across two or more indices, such as rows and columns (2D) — e.g. int A[3][4];, accessed as A[1][2]. They are used to represent structures like matrices, tables, and grids that a single index cannot conveniently model.

Q17
LQ (b)
Describe the limitations of arrays in C programming. Implement a program in C to multiply two matrices using multi-dimensional arrays.
Answer
  • Fixed, static size — must be known at compile time and cannot be resized at run time.
  • Can store only homogeneous data (all elements of the same type).
  • Inserting or deleting elements is expensive since it requires shifting existing elements.
  • No automatic bounds checking, which can lead to out-of-range access errors.
  • Memory can be wasted if the declared size exceeds the actual data stored.
Example Program
// Multiply two matrices (2x2 example, generalizes to any compatible size)
#include <stdio.h>

int main() {
    int A[2][2], B[2][2], C[2][2];
    int i, j, k;

    printf("Enter elements of matrix A (2x2):\n");
    for (i = 0; i < 2; i++)
        for (j = 0; j < 2; j++)
            scanf("%d", &A[i][j]);

    printf("Enter elements of matrix B (2x2):\n");
    for (i = 0; i < 2; i++)
        for (j = 0; j < 2; j++)
            scanf("%d", &B[i][j]);

    for (i = 0; i < 2; i++) {
        for (j = 0; j < 2; j++) {
            C[i][j] = 0;
            for (k = 0; k < 2; k++)
                C[i][j] += A[i][k] * B[k][j];
        }
    }

    printf("Product matrix:\n");
    for (i = 0; i < 2; i++) {
        for (j = 0; j < 2; j++)
            printf("%d ", C[i][j]);
        printf("\n");
    }

    return 0;
}
Output (sample: A={{1,2},{3,4}}, B={{5,6},{7,8}})
Product matrix:
19 22
43 50

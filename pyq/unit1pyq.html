Q1
MCQ
How to find 210 in a C program?
  • (a) 2^10
  • (b) 2**10
  • (c) 2power(10)
  • (d) None of the above
✓ Correct option: (d) None of the above

C has no built-in power operator. The ^ symbol is the bitwise XOR operator, not exponentiation, and **/power() are not valid C syntax. To compute 210 you must use pow(2, 10) from math.h, or multiply manually / use a loop or bit-shift (1 << 10).

Q2
MCQ
Which of the following is a valid identifier in C?
  • (a) _student*name
  • (b) _student#name
  • (c) _student_name
  • (d) _student@name
✓ Correct option: (c) _student_name

An identifier in C can only contain letters, digits, and underscores, and must not start with a digit. Special characters like *, #, and @ are not allowed, which rules out (a), (b), and (d).

Q3
VSQ
What is the difference between a constant and a variable?
Answer

A constant is a fixed value that cannot be changed during program execution (e.g. 10, 'A', or a value declared with const/#define). A variable is a named memory location whose value can be assigned and modified any number of times while the program runs (e.g. int age = 20; where age can later be updated).

Q4
VSQ
Give an example of a ternary operator.
Answer
int a = 10, b = 20, max;
max = (a > b) ? a : b;   // max becomes 20

The ternary (conditional) operator ?: takes three operands — a condition, a value if true, and a value if false — and evaluates one expression in place of an if...else statement.

Q5
SQ
What do you mean by the precedence and associativity of an operator?
Answer

Precedence determines which operator is evaluated first when an expression contains two or more different operators — for example, * and / have higher precedence than + and -, so multiplication/division is done before addition/subtraction.

Associativity decides the evaluation order when operators of the same precedence appear together. Most operators (like +, -, *, /) are left-to-right associative, while a few (like assignment = and unary operators) are right-to-left associative.

Example: in a + b * c, * runs first due to precedence. In a - b - c, left-to-right associativity means it evaluates as (a - b) - c.

Q6
SQ
What do you mean by compilation and pre-processing?
Answer

Pre-processing is the first step, handled by the preprocessor before actual compilation. It processes directives that begin with # — such as #include (inserts header file contents), #define (macro substitution), and conditional compilation directives like #ifdef — producing an expanded source file.

Compilation then converts this preprocessed source code into object code (machine-level instructions) through stages like lexical analysis, syntax analysis, semantic analysis, and code generation. The compiler also checks the code for syntax errors.

Q7
LQ
Explain the different types of operators in C.
Answer
  • Arithmetic operators: + - * / % — perform mathematical calculations.
  • Relational operators: < > <= >= == != — compare two values, result is true/false.
  • Logical operators: && || ! — combine or invert conditions.
  • Bitwise operators: & | ^ ~ << >> — operate on individual bits of integer data.
  • Assignment operators: = += -= *= /= %= — assign and update values.
  • Increment/decrement operators: ++ and -- — increase or decrease a variable by 1 (prefix or postfix).
  • Conditional (ternary) operator: ?: — shorthand for if-else in an expression.
  • Comma operator: , — evaluates multiple expressions, returning the last one.
  • sizeof operator: returns the size (in bytes) of a data type or variable.
Q8

Which of the following is not a valid keyword in C?
  • (i) int
  • (ii) float
  • (iii) string
  • (iv) char
✓ Correct option: (iii) string

string is not a keyword or built-in type in C (that's a C++ construct). C uses char arrays or pointers to represent text. int, float, and char are all reserved keywords in C.

Q9
MCQ (b)
Which of the following is a valid identifier?
  • (i) 123abc
  • (ii) a + b
  • (iii) int
  • (iv) _identifier
✓ Correct option: (iv) _identifier

Identifiers cannot start with a digit (rules out i), cannot contain spaces or operators (rules out ii), and cannot be a reserved keyword (rules out iii, since int is reserved). Starting with an underscore is valid, so _identifier is correct.

Q10
MCQ (h)
What is the output? int a = 5; printf("%d", a++);
  • (i) 4
  • (ii) 6
  • (iii) Error
  • (iv) 5
✓ Correct option: (iv) 5

a++ is the postfix increment: it returns the current value of a (5) to printf first, and only after that increments a to 6. So the printed output is 5.

Q11
MCQ (i)
What is the range of values for a signed char?
  • (i) -256 to 255
  • (ii) -128 to 127
  • (iii) 0 to 255
  • (iv) -32768 to 32767
✓ Correct option: (ii) -128 to 127

A char is 1 byte (8 bits). As a signed type, one bit is used for the sign, giving a range of -128 to 127. (0 to 255 is the range for an unsigned char, and -32768 to 32767 is the range of a 2-byte signed int on 16-bit systems.)

Q12
MCQ (j)
What will 5/2 evaluate to in C if both operands are integers?
  • (i) 2.5
  • (ii) 2
  • (iii) 3
  • (iv) Undefined
✓ Correct option: (ii) 2

When both operands of / are integers, C performs integer division and truncates (discards) the fractional part rather than rounding. So 5 / 2 gives 2, not 2.5.

Q13
VSQ (a)
What is the role of a preprocessor directive in C programming? Give an example.
Answer

A preprocessor directive instructs the preprocessor to perform text substitution or file inclusion on the source code before compilation begins. Directives always start with # and are not terminated by a semicolon.

#include <stdio.h>   // includes the standard I/O header
#define PI 3.14159  // defines a macro constant
Q14
VSQ (b)
Define the precedence and associativity of operators in C with example. Why are they important?
Answer

Precedence decides which operator binds tighter among different operators; associativity decides the order of evaluation among operators of equal precedence (left-to-right or right-to-left).

Example: 10 + 5 * 2 evaluates to 20 (not 30) because * has higher precedence than +. They matter because without fixed rules, the same expression could produce different, ambiguous results — precedence and associativity guarantee every C compiler evaluates an expression the same, predictable way.

Q16
SQ (a)
Explain the role of a compiler in C programming. Discuss the phases of compilation and pre-processing in detail.
Answer

A compiler translates human-readable C source code into machine/object code that the computer's processor can execute, while also checking the program for syntax and some semantic errors.

Preprocessing (before compilation): handles directives such as #include (inserts header files), #define (macro expansion), and #ifdef/#endif (conditional compilation), producing an expanded translation unit.

  • Lexical analysis: breaks source code into tokens (keywords, identifiers, operators, literals).
  • Syntax analysis (parsing): checks tokens against C grammar rules and builds a parse tree.
  • Semantic analysis: checks type compatibility and meaning (e.g. correct use of variables).
  • Intermediate code generation: produces a machine-independent intermediate representation.
  • Code optimization: improves the intermediate code for speed/size.
  • Target code generation: converts optimized code into assembly/object (machine) code.
  • Linking: combines object code with library code to produce the final executable.
Q17
SQ (b)
Explain the various operators in C programming with examples (Include arithmetic, logical, bitwise, and conditional operators).
Answer
  • Arithmetic operators (+ - * / %): perform basic math. Example: a + b, a % b (remainder).
  • Logical operators (&& || !): combine boolean conditions. Example: (a > 0 && b > 0) is true only if both are positive.
  • Bitwise operators (& | ^ ~ << >>): act on the binary representation of integers. Example: a & b performs bit-by-bit AND; a << 1 shifts bits left, doubling the value.
  • Conditional (ternary) operator (?:): a compact if-else. Example: max = (a > b) ? a : b;
Q18
LQ (a)
Discuss the different data types available in C, their memory representation, size, and range. Discuss the significance of modifiers (short, long, signed, unsigned) for data types in C with example.
Answer

C provides several basic (primitive) data types, each stored differently in memory:

  • int: typically 4 bytes, stores whole numbers, range roughly -2,147,483,648 to 2,147,483,647.
  • char: 1 byte, stores a single character (or small integer), range -128 to 127 (signed) or 0 to 255 (unsigned).
  • float: 4 bytes, stores single-precision floating-point numbers (~6-7 significant digits).
  • double: 8 bytes, stores double-precision floating-point numbers (~15-16 significant digits), used when higher accuracy is needed.

Internally, integer types are stored as binary two's-complement values, and floating types are stored using the IEEE-754 format (sign bit, exponent, mantissa).

Modifiers adjust the size/range of a base type:

  • short reduces the storage size (e.g. short int is often 2 bytes).
  • long increases the storage size (e.g. long int is often 8 bytes, long long int even larger).
  • signed (default) allows both negative and positive values.
  • unsigned uses the sign bit for magnitude instead, doubling the positive range but disallowing negative values — e.g. unsigned int ranges from 0 to 4,294,967,295 instead of roughly ±2.1 billion.

Choosing the right type/modifier combination balances memory usage against the range and precision a program needs.

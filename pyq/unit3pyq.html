Q1
MCQ
Which pointer can point to a variable of any data type?
  • (a) generic
  • (b) NULL
  • (c) wild
  • (d) dangling
✓ Correct option: (a) generic

A generic pointer (declared as void *) can point to a variable of any data type since it carries no type information of its own — it must be cast before dereferencing. A NULL pointer points to nothing, a wild pointer is uninitialized (points to a random location), and a dangling pointer points to memory that has already been freed.

Q2
MCQ
Which of the following storage classes is suitable for faster execution of a program?
  • (a) auto
  • (b) register
  • (c) static
  • (d) extern
✓ Correct option: (b) register

The register storage class suggests storing a variable in a CPU register (when possible) rather than main memory, allowing much faster access — useful for variables like loop counters that are accessed frequently.

Q3
MCQ
Which of the following statements is CORRECT?
  • (a) Function declaration specifies only the function name and its return type
  • (b) A function can call itself
  • (c) A function definition must contain a return statement
  • (d) A function written by a user is called a built-in function
✓ Correct option: (b) A function can call itself

This is recursion — a function calling itself is completely valid in C. The other statements are false: a function declaration (prototype) must also specify the parameter types, not just the name and return type; a void function need not contain a return statement; and a user-written function is a user-defined function, not a built-in one (built-in functions come from the standard library).

Q4
VSQ
What does the auto storage class indicate?
Answer

auto is the default storage class for local variables inside a function or block. Such variables are automatically created when the block is entered and automatically destroyed when it exits, and have local scope with an uninitialized default value. Writing auto int x; is equivalent to just writing int x; inside a function.

Q5
VSQ
Write the syntax of the strcpy() function.
Answer
char *strcpy(char *dest, const char *src);

strcpy() (declared in string.h) copies the string pointed to by src, including the null terminator, into the buffer pointed to by dest, and returns dest.

Q6
VSQ
Give an example of pointer arithmetic.
Answer
int arr[] = {10, 20, 30};
int *p = arr;      // p points to arr[0]

p++;                // p now points to arr[1] (address moves by sizeof(int))
printf("%d", *p);  // prints 20

When a pointer is incremented, it advances by the size of the type it points to (here, 4 bytes for int), not by 1 byte — this lets pointers move naturally element-by-element through an array.

Q7
VSQ
Write a recursive function to find the factorial of a number.
Answer
int factorial(int n) {
    if (n == 0 || n == 1)
        return 1;         // base case
    return n * factorial(n - 1);  // recursive case
}

The function keeps calling itself with a smaller value of n until it hits the base case (n == 0 or 1), then the results multiply back up the call stack.

    int temp = *a;

    *b = temp;

Q10
SQ
Write a C program to demonstrate the use of a user-defined function to check whether a number is a palindrome or not.
Example Program
// Palindrome check using a user-defined function
#include <stdio.h>

int isPalindrome(int n) {
    int original = n, reversed = 0, digit;
    while (n > 0) {
        digit = n % 10;
        reversed = reversed * 10 + digit;
        n /= 10;
    }
    return (original == reversed);
}

int main() {
    int num = 121;
    if (isPalindrome(num))
        printf("%d is a palindrome\n", num);
    else
        printf("%d is not a palindrome\n", num);
    return 0;
}
Output
121 is a palindrome
Q11
LQ
What do you mean by dynamic memory management? Explain various dynamic memory management functions.
Answer

Dynamic memory management is the allocation and deallocation of memory at run time (from the heap) rather than at compile time, allowing a program to request exactly the amount of memory it needs while it is running, and release it when no longer needed. It is essential when the required memory size isn't known in advance.

  • malloc(size) — allocates a block of size bytes with uninitialized (garbage) content, and returns a void* pointer to it (or NULL on failure).
  • calloc(n, size) — allocates memory for n elements of size bytes each, and initializes all bytes to zero.
  • realloc(ptr, newSize) — resizes a previously allocated block to newSize, preserving existing content as far as it fits.
  • free(ptr) — releases previously allocated memory back to the system, preventing memory leaks.
#include <stdlib.h>

int *arr = (int*) malloc(5 * sizeof(int));
if (arr != NULL) {
    // use arr[0..4]
    free(arr);
}
Q12
LQ
Write a program to sort an array of integers using pointers. Explain how pointer arithmetic helps in sorting.
Answer

Since an array name decays to a pointer to its first element, and array elements are stored contiguously, a pointer can be advanced (p+i) to reach any element without using array-index syntax. This lets a sort compare and swap elements purely through pointer dereferencing and pointer arithmetic, which is often closer to how the compiler accesses memory and can be marginally faster.

Example Program (Bubble sort using pointers)
#include <stdio.h>

void sortArray(int *arr, int n) {
    int i, j, temp;
    for (i = 0; i < n - 1; i++) {
        for (j = 0; j < n - i - 1; j++) {
            if (*(arr + j) > *(arr + j + 1)) {
                temp = *(arr + j);
                *(arr + j) = *(arr + j + 1);
                *(arr + j + 1) = temp;
            }
        }
    }
}

int main() {
    int nums[] = {5, 2, 9, 1, 7};
    int n = 5, i;

    sortArray(nums, n);

    printf("Sorted array: ");
    for (i = 0; i < n; i++)
        printf("%d ", *(nums + i));

    return 0;
}
Output
Sorted array: 1 2 5 7 9

MCQ (e)
What does *ptr mean in C?
  • (i) Value stored at the address ptr points to
  • (ii) Address of ptr
  • (iii) Declaring ptr as a pointer
  • (iv) None of the above
✓ Correct option: (i) Value stored at the address ptr points to

When used on an already-declared pointer, * is the dereference operator — it accesses (reads or writes) the value at the memory address the pointer holds. (* only means "declare a pointer" when it appears in a type declaration like int *ptr;.)

Q14
MCQ (f)
What is the scope of a variable declared with the static keyword?
  • (i) Local to the block and persists between function calls
  • (ii) Global across the program
  • (iii) Local only to the function
  • (iv) Dynamic
✓ Correct option: (i) Local to the block and persists between function calls

A static local variable keeps its scope restricted to the block it's declared in (like a normal local variable), but unlike auto variables, it retains its value between successive calls to the function because it's allocated for the lifetime of the program rather than the lifetime of the block.

Q15
VSQ (f)
Define a pointer. What is a NULL pointer, and when is it used?
Answer

A pointer is a variable that stores the memory address of another variable, rather than a data value directly. It is declared using *, e.g. int *p;.

A NULL pointer is a pointer explicitly assigned the value NULL (typically 0), meaning it points to no valid memory location. It is commonly used to initialize a pointer before it's assigned a real address, and to signal or check "no value" — for example, checking if (ptr == NULL) after a malloc() call to detect allocation failure.

Q16
VSQ (g)
Explain the difference between call-by-value and call-by-reference with examples.
Answer

In call-by-value, a copy of the argument's value is passed to the function, so changes made inside the function do not affect the original variable. In call-by-reference (simulated in C using pointers), the address of the argument is passed, so the function can modify the original variable directly.

// Call-by-value: original is unchanged
void modify(int x) { x = 100; }

// Call-by-reference: original is changed
void modifyRef(int *x) { *x = 100; }

int a = 5;
modify(a);       // a is still 5
modifyRef(&a);   // a becomes 100
Q17
VSQ (h)
What are storage classes in C? Describe the purpose of the static storage class.
Answer

Storage classes in C determine a variable's scope (visibility), lifetime (how long it exists in memory), default initial value, and storage location. C provides four: auto, register, static, and extern.

The static storage class makes a variable retain its value across function calls (for local variables) instead of being destroyed when the block ends, and, when applied to a global variable or function, restricts its visibility to the file it's declared in. It's commonly used for counters that must persist between calls, such as tracking how many times a function has been invoked.

Q18
SQ (g)
Explain the difference between dynamic and static memory allocation in C. Include examples of malloc, calloc, and realloc.
Answer

Static memory allocation happens at compile time — the size and type of variables (e.g. int arr[10];) are fixed before the program runs, and memory is allocated on the stack. Dynamic memory allocation happens at run time — memory is requested from the heap as needed using library functions, and the size can be decided while the program is running.

#include <stdlib.h>

// malloc: allocates uninitialized memory
int *a = (int*) malloc(5 * sizeof(int));

// calloc: allocates and zero-initializes memory
int *b = (int*) calloc(5, sizeof(int));

// realloc: resizes a previously allocated block
b = (int*) realloc(b, 10 * sizeof(int));

free(a);
free(b);

Q20
LQ (c)
Discuss the various types of storage classes in C (auto, static, register, extern). Provide examples.
Answer
  • auto: the default storage class for local variables — scope is local to the block, lifetime lasts only while the block executes, and default value is garbage/undefined.
  • register: requests that a variable be stored in a CPU register for faster access (the compiler may ignore this if no register is available) — scope and lifetime are the same as auto, but the address-of operator (&) cannot be used on it.
  • static: scope is local to the block (or file, for globals/functions), but lifetime extends across the entire program — the value persists between function calls, and default value is 0.
  • extern: declares a variable or function that is defined elsewhere (often in another file), giving it global scope and program lifetime without allocating new storage for it.
void counter() {
    auto int a = 0;      // resets to 0 every call
    static int b = 0;    // retains value between calls
    register int c;    // requested to live in a CPU register

    a++; b++;
    printf("a = %d, b = %d\n", a, b);
}

// in another file:
extern int globalCount;  // refers to a variable defined elsewhere
